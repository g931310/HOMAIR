# HOMAIR Roadmap

HOMAIR is being developed as a reusable public reproducibility core
for explainable clinical machine-learning workflows.

## v1.0
- Public reproducibility core
- Synthetic example dataset
- Five-fold out-of-fold validation
- Nested threshold validation
- Statistical model comparison
- SHAP utilities

## Planned
- Automated reproducibility tests
- Additional reusable validation utilities
- Improved documentation and examples
- Continuous-integration testing
- Reproducibility metadata for future manuscript versions

## Scope

Participant-level MJ Health Database data, proprietary database mappings,
trained deployment models, and internal research workflows are outside
the scope of the public repository.
